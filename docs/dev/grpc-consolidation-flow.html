JS Durable Functions gRPC 合并路径

这个页面展示最终目标流：JS v4 worker indexing 生成 Durable 绑定元数据， Durable Extension 看到 durableRequiresGrpc 后打开本地 gRPC 通道， JS 侧只负责显式 opt-in、base64 边界和调用 durabletask-js 公共执行/客户端 API。

JS v4 应用 使用 app.orchestration / activity / entity / client 注册函数。
Worker Indexing 输出 raw binding metadata；opt-in 时包含 durableRequiresGrpc。
Durable Extension 已有公共支持：看到标记后调用 ConfigureForGrpcProtocol。
本地 gRPC Extension 和语言 worker 之间传 OrchestratorRequest / EntityBatchRequest。
Client 函数 Durable client input 同样可带 durableRequiresGrpc。
Task Hub 调度实例、事件、实体信号；状态仍由 Durable 后端管理。
Orchestrator worker 收到 base64 protobuf，请 durabletask-js 执行 replay。
Activity / Entity 活动直接执行；实体批处理走 EntityBatchRequest。
base64 protobuf 响应 JS adapter 只做 base64 边界；protobuf 和运行时语义由 durabletask-js 拥有。

    范围边界：v1 function.json 不进入这条 gRPC 合并路径；JS 不复制 extension 或 durabletask-js 已有公共工作。
